# 🚀 EraseMark AI

AI-powered watermark remover built with HTML, CSS, JavaScript and Vercel Serverless Functions.

---

## ✨ Features

- AI Watermark Removal
- Drag & Drop Upload
- PNG, JPG & WEBP Support
- Fast Image Processing
- Secure Upload Validation
- Responsive UI
- Dark Modern Theme
- Vercel Ready
